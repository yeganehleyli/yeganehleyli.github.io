Automation, AI & prototyping

Workflow automation

n8n

What it is

A visual workflow tool that passes information between apps through a series of connected steps.

Practical example

When a lesson draft is ready, a workflow can add it to a review queue and notify the editor. The editor decides what is ready to publish.

App prototyping

Lovable

What it is

An AI-assisted app builder that turns a description into a working web prototype.

Practical example

Sketch a learner’s path from a scenario to a decision and feedback. Try the prototype with a colleague to see whether the next step is clear.

Interface design

Figma

What it is

A collaborative design tool for laying out screens and connecting them into clickable prototypes.

Practical example

Prototype the “try again” path in a practice activity. Ask a learner to find their feedback and revise their answer before the team builds the final interface.

Development environments

Docker

What it is

Docker packages an application and its dependencies into containers so it can run in a consistent environment.

Practical example

For a coding workshop, package a sample project and its libraries together. That lets learners spend their first session on the exercise instead of resolving setup differences.

Generative AI

ChatGPT

What it is

An AI assistant that can help draft explanations, propose examples and revise instructional text.

Practical example

Draft two explanations of rate of change: one built around a table and another around a graph. Check the mathematics and reading level before either version reaches learners.

Generative AI

Gemini

What it is

An AI assistant that can work with prompts, documents and images to suggest explanations or questions.

Practical example

Use a sample graph to draft interpretation questions. Check the axes, units and answer choices against the graph before adding the questions to a lesson.

Teaching & collaboration

Interactive video

EdPuzzle

What it is

A tool for turning a video into a lesson by adding questions at chosen points in the recording.

Practical example

Pause a demonstration just before the result. Ask learners to predict what will happen and explain why, then use their responses to decide which step to revisit.

Course delivery

Moodle

What it is

A learning management system for organizing course resources, activities, assessments and feedback.

Practical example

Build a weekly module around one worked example and a short practice quiz. Link the feedback for a missed question to the part of the lesson that explains it.

Course delivery

Canvas

What it is

A learning management system that brings modules, assignments, rubrics and feedback together in one course.

Practical example

Place a design brief, a sample submission and a rubric in the same module. Learners can compare their drafts with the criteria before they submit.

Collaboration

Google Workspace

What it is

A collection of tools, including Docs, Sheets and Drive, for writing, organizing files and reviewing work together.

Practical example

Draft a storyboard in Docs and collect comments in context. A shared Sheet can track which revisions need a decision and which are complete.

Instructional materials

Microsoft Office

What it is

Word, PowerPoint and Excel support writing, presenting and working with data.

Practical example

Prepare a facilitator guide in Word and its companion slides in PowerPoint. Compare the activity prompts side by side so the facilitator and learners receive consistent instructions.

Collaborative learning

Padlet

What it is

A shared digital board where participants can post ideas, examples and responses.

Practical example

Invite learners to post a sketch of their solution and respond to a peer who took a different approach. Use the two sketches to start a discussion about the reasoning behind each choice.

Immersive learning

VR / AR

What it is

Virtual reality (VR) places a learner inside a simulated environment. Augmented reality (AR) adds digital information to a view of the physical world.

Practical example

A learner could rehearse a procedure in a virtual lab or use AR labels to identify the same equipment on a real bench. Both activities can work toward the same learning goal.

Data & research

Statistical analysis

SPSS

What it is

A statistical software package for summarizing data and examining differences or relationships.

Practical example

For paired pre- and post-assessments, check which scores can be matched, then summarize the changes. The study design guides how those changes can be interpreted.

Programming and analysis

Python

What it is

A programming language for processing data, automating repeated tasks and building visualizations.

Practical example

Turn a table of distances and times into a graph. Let learners change a value, predict what will happen to the slope and compare their prediction with the new plot.

Spreadsheet analysis

Excel

What it is

A spreadsheet tool for organizing records, applying formulas and visualizing patterns.

Practical example

Use a pivot table to count missed responses by question. Read the most frequently missed item alongside its learning objective before deciding what to revise.

Research design

Mixed-methods research

What it is

An approach that brings numerical results and qualitative evidence together to answer a research question.

Practical example

In the preschool sequencing project, all four children ordered the four pictures correctly after instruction, while two still needed prompts to use the materials. Reading the observations alongside the scores helps distinguish sequencing from independent use.

Accessibility & review

Inclusive design

Accessibility

What it is

Designing materials so people with different abilities can perceive the content, navigate it and take part in the activity.

Practical example

Complete a lesson using only a keyboard. Check that focus stays visible and give each graph a text description that explains the relationship learners are meant to notice.

Review and revision

Peer review

What it is

A structured way for colleagues to examine work against agreed criteria and offer specific feedback.

Practical example

Ask a reviewer to complete a practice task using only the learner instructions. Where their interpretation differs from the intended task, revise the wording and try it again.
